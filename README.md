# NPO-Updater-Theme-Changer-V5

Official data repository for **NP Optimizer** (read by the app from `raw.githubusercontent.com/.../main/`).

| File | Purpose |
|---|---|
| `schedule.json` | Which theme runs on which dates (`"05-15"` = every year, `"2027-05-15"` = that year only). First match wins; outside every range the app uses `theme.json`. Edit it in NPO Admin > Schedule. |
| `theme.json` | The default theme (used when no schedule entry matches). The app checks at startup and every ~20 min and re-skins itself live. |
| `themes/*.NPO` | Theme files: colours + animation effects + banner message. Classic, Neon, Monsoon, Christmas, Winter, Vesak, Avurudu, Halloween, NewYear2027. |
| `Set-Theme.ps1` | Copies a theme to `theme.json` with a bumped version. `.\Set-Theme.ps1 Vesak -Push` |
| `update.json` | **Signed** update manifest, generated by `Release.ps1` / `NPOKeygen signupdate`. Do not edit by hand (the signature would break and the app would ignore it). |
| `revoked.json` | `{"ids":["LICENSEID"],"hwids":["XXXX-..."]}` : listed licenses are locked the next time the app goes online. |

Branch must be `main`. Colours are `#RRGGBB` only; anything else is ignored by the app.

## Making a new theme (any time, no app update)
A `.NPO` file is JSON: `name`, `season`, `message` (banner shown for ~10 s at startup), `colors` (8 x `#RRGGBB`) and `effects`.
Effects the app can draw: `snow, rain, stars, kudu, skylanterns, lamps, fireworks, confetti, petals, sun, bats, ghosts, pumpkins, spider`.
Create it in NPO Admin > Themes > Create custom theme, add it to the Schedule, push. New effect *types* need an app update; new themes using existing effects do not.
